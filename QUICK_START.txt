QUICK COMMANDS:
================================================================================

1️⃣  PUSH TO GITHUB
   cd ~/Documents/Projects/ai-commit-sparkle
   
   # First, create repo at: https://github.com/new
   # Name: ai-commit-sparkle
   # Public, no initialization
   
   git remote add origin https://github.com/akshay-snpune/ai-commit-sparkle.git
   git branch -M main
   git push -u origin main

2️⃣  GET MARKETPLACE TOKEN
   • Go to: https://marketplace.visualstudio.com
   • Click "Publish extensions"
   • Sign in with GitHub
   • Go to: https://marketplace.visualstudio.com/manage
   • Create Publisher: akshay-snpune
   • Generate PAT at: https://dev.azure.com/_usersSettings/tokens
   • Scope: Marketplace (manage)
   • Copy and save your PAT (you won't see it again!)

3️⃣  PUBLISH TO MARKETPLACE
   npm install -g @vscode/vsce
   cd ~/Documents/Projects/ai-commit-sparkle
   vsce publish --pat YOUR_PAT_HERE

   Expected output:
   ✓ Published akshay-snpune.ai-commit-sparkle@0.1.0
   ✓ Available on marketplace in 5-15 minutes

4️⃣  VERIFY (Wait 15 mins, then check)
   https://marketplace.visualstudio.com/items?itemName=akshay-snpune.ai-commit-sparkle

5️⃣  SETUP AUTO-PUBLISHING (Optional)
   • Go to: https://github.com/akshay-snpune/ai-commit-sparkle/settings/secrets/actions
   • Create secret: VSCODE_MARKETPLACE_TOKEN = YOUR_PAT
   • Now: npm version minor && git push origin main --tags
   • GitHub Actions publishes automatically!
