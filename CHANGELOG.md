# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2024-08-05

### Added

- Initial release
- Sparkle button in Source Control panel for quick commit message generation
- Ollama provider support (local AI models)
- OpenAI provider support (GPT models via API)
- Configurable AI model selection
- Custom instructions support
- Conventional Commits format by default
- Error handling and user notifications
- Full TypeScript implementation
- Comprehensive documentation and troubleshooting guide

### Features

- One-click commit message generation
- Support for multiple AI backends
- Configurable endpoints and models
- Settings UI for easy configuration
- Progress notifications during generation
